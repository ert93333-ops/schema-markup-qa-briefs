# Schema Markup QA Briefs

Static MVP for checking pasted JSON-LD and visible-page summaries before publishing structured data.

## Offer

Paste JSON-LD, visible-page summary, page URL, intended schema type, and template owner. Generate a copyable QA brief covering:

- JSON syntax and JSON-LD block extraction
- detected schema types
- required and recommended fields
- Product offer checks
- visible-page mismatch warnings
- duplicate entity warnings
- URL and image checks
- official Rich Results Test and crawlability reminders

## Conversion Path

Billing is not connected. The MVP uses early-access, demo-request, and purchase-intent capture with a public-safe GitHub issue handoff.
